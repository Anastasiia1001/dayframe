# Dayframe

Особистий простір для роботи й життя на React, TypeScript, Vite, Tailwind та Lucide. Український інтерфейс, читабельний шрифт, насичені пастельні теми, особисті завдання й підключення Outlook, Календаря Google та Slack лише для читання. Jira та Confluence вимкнені.

## Запуск

Потрібен Node.js 24 або новіший:

```sh
npm ci --cache /tmp/dayframe-npm-cache
npm run build
npm start
```

Сервер віддає зібраний застосунок на порту 4317. Без налаштування OAuth усі зовнішні джерела показують стан **Не підключено**. Для знайомства відкрий **Налаштування → Спробувати деморежим**. Особисті завдання працюють без підключення облікових записів.

`npm run dev` запускає Vite на порту 5173 і пересилає `/api` на сервер. Для локальної авторизації значення `DAYFRAME_PUBLIC_URL` і зареєстровані адреси повернення мають відповідати порту 5173. `npm run preview` показує лише статичну збірку й не запускає сервер авторизації.

## Підключення

Спочатку підключи робочий і особистий Outlook, потім Календар Google та Slack. Потрібні серверний хостинг і одноразова реєстрація OAuth-застосунків. [Інструкція з підключення](docs/CONNECTIONS.md) містить дозволи, адреси повернення та назви змінних середовища. Секрети зберігаються лише в налаштуваннях серверного хостингу.

- `server/config.mjs` — адреси сервісів, дозволи лише для читання та вимоги до конфігурації.
- `server/app.mjs` — обмін кодів авторизації, PKCE для Microsoft і Google, перевірка стану, захищені HttpOnly-сеанси, оновлення токенів, API читання даних і розміщення інтерфейсу.
- `server/mappers.mjs` — перетворення відповідей сервісів на спільні моделі з урахуванням часового поясу.
- `src/data/live.ts` — типізований клієнт API. Токени не потрапляють у localStorage.
- `src/useWorkspace.ts` — власні й демонстраційні дані, оновлення, часткові помилки, усунення дублікатів і вибір періоду.
- `src/components/IntegrationSettings.tsx` — стани підключень, авторизація, відключення та вибір каналів Slack.
- `src/data/mock*.ts`, `providers.ts` — окремі демонстраційні дані українською. Приклади Jira та Confluence не використовуються застосунком.
- `src/appearance.ts` — каталог 14 тем і 6 маскотів; вибір зберігається локально.
- `src/components/Mascot.tsx` — оригінальні SVG-персонажі з пружними рухами, помахами та святкуванням виконаних завдань. Анімації враховують системне зменшення руху.
- `src/locale.ts` — українські підписи, локальний формат дат і правила відмінювання числівників. Внутрішні ключі збережених налаштувань не перекладаються.
- `src/types.ts` — типи моделей.
- `src/App.tsx` — розділи «Сьогодні», «Календар», «Робота», «Особисте», пошук, сповіщення та редагування завдань.
- `src/styles.css` — адаптивний вигляд, чотирнадцять тем і підтримка зменшення анімацій.

Дані Slack — результати пошуку, а не ШІ-огляд. Зовнішні джерела доступні лише для читання. Серверні сеанси зберігаються в пам’яті, діють до восьми годин і потребують повторного підключення після перезапуску. Особисті завдання й налаштування зберігаються в браузері. Виконані повторювані завдання знову відкриваються, коли настає наступна дата й застосунок відкритий. Фонового планувальника та синхронізації між пристроями немає.

Українізація не змінює користувацькі назви, власні нотатки чи тексти з реальних сервісів. У незмінених початкових завдань перекладаються лише назви; їхні дати, стани та правила повторення зберігаються.

## Публікація

GitHub Pages автоматично публікує статичні файли після змін у `main`. Там працюють особисті завдання й явно позначений деморежим. Реальні підключення потребують серверної версії: скористайся шаблоном `render.yaml` або іншим хостингом Node.js 24. Збірка: `npm ci && npm run build`; запуск: `npm start`. На серверному хостингу налаштуй адресу HTTPS та облікові дані OAuth. Сам шаблон не створює хостинг.

## Mac

[Установлення та варіанти збірки для Mac](docs/MAC.md). У Safari на macOS Sonoma або новішій можна додати Dayframe до Dock як окремий вебзастосунок. Нативний інсталятор `.dmg` зараз не створюється.

## Перевірки

```sh
npm test
npm run build
npx playwright install chromium
npm run test:browser
```

Серверні тести перевіряють стан авторизації, PKCE, відсутню конфігурацію, незалежне підключення двох Outlook, відключення, оновлення токенів, пагінацію, часові пояси та читання Slack на локальних прикладах. Реальні облікові дані не використовуються. Браузерні тести перевіряють навігацію, українські підписи, завдання, збереження даних, режими джерел та мобільний вигляд. Реальна авторизація залишається неперевіреною, доки облікові записи не налаштовані та не підключені.

Якщо Chromium уже встановлений, укажи шлях до нього в `PLAYWRIGHT_CHROMIUM_EXECUTABLE` замість завантаження браузера. Команда `npm run test:browser` за потреби запускає сервер із готової збірки.


## Практичне планування

Підходи та межі порівняння популярних календарів описані в [рішеннях щодо інтерфейсу](docs/DESIGN-DECISIONS.md). Зовнішні офіційні сторінки під час роботи були недоступні через мережеву відмову; це не живий аудит усіх сервісів.

Головна показує розклад і до чотирьох актуальних справ; завершені згорнуті. «Особисте» розділяє сьогодні, найближчі сім днів, усі справи та необов’язкові шаблони. Побутові заготовки не є активними завданнями, доки їх не заплановано. Позначки дати, прострочення, повторення й важливості пояснюють різницю між справами.

- `src/components/CalendarBoard.tsx` — шкала часу, день/тиждень/місяць/список, фільтри, перехід до дати та окремі завдання без часу.
- `src/components/PersonalBoard.tsx`, `TaskList.tsx` — згруповані списки, пошук, завершення, перенесення, редагування й бібліотека.
- `src/components/EventDetails.tsx` — подробиці події з посиланнями лише за наявності справжніх адрес.
- `src/domain/planning.ts` — коректне переміщення дат, прострочені справи, перекриття подій, перехід через північ і обережна міграція старих заготовок.

Перенесення виправлено: локалізована дата більше не використовується як машинна. Конкретні завдання зі Slack створюються лише після введення назви й підтвердження, а не з цілого абзацу повідомлення автоматично.

### Беклог і Jira вручну

«Особисте» — єдиний простір без вкладок: беклог поруч із колонками «Сьогодні», «Завтра» та «Пізніше» (перетягування сюди планує через 7 днів). Перетягуй картки за маркер ⠿ або користуйся кнопками й вибором дати. Звичайні завдання переміщуються, шаблони створюють копію. Завдання можна повернути в беклог без дати: воно не потрапляє в календар або список на сьогодні. Виконані й призупинені справи розгортаються нижче в цьому ж просторі.

«＋ У беклог» створює ідею без дати. «Додати з Jira вручну» зберігає вставлену назву як разове завдання у беклозі; необов’язкове HTTPS-посилання відкриває оригінальний тікет. Це локальна копія без API або синхронізації статусів. Дані зберігаються в цьому браузері.
