# Dayframe

Особистий простір для роботи й життя на React, TypeScript, Vite, Tailwind та Lucide. Український інтерфейс, читабельний шрифт, насичені пастельні теми, особисті завдання й підключення Outlook, Календаря Google та Slack лише для читання. Confluence вимкнена. Jira Cloud підтримується лише для читання.

## Осінь, Хеловін і погодний помічник

У галереї оформлення є «Осінь · Бурштиновий затишок» і «Хеловін · Гарбузова ніч». У календарі та «Сьогодні» більший персонаж об’єднаний із погодою; температура відкриває подробиці та зміну міста. [Оформлення, сезонні деталі, перевірки та обмеження](docs/AUTUMN-WEATHER.md).

## Тематичне скло та перепочинок

Усі теми використовують спільні скляні матеріали зі збереженням власних палітр. У налаштуваннях є «Зменшити прозорість». «Перепочинок» містить ручну дихальну паузу, особисті локальні записи та перегляд змін для полегшення дня зі скасуванням. Записи цього куточка не входять до пошуку й загальної резервної копії. [Поведінка, приватність, перевірки та обмеження](docs/GLASS-REST.md).

## Запуск

Потрібен Node.js 24 або новіший:

```sh
npm ci --cache /tmp/dayframe-npm-cache
npm run build
npm start
```

Сервер віддає зібраний застосунок на порту 4317. Без налаштування OAuth усі зовнішні джерела показують стан **Не підключено**. Для знайомства відкрий **Налаштування → Спробувати деморежим**. Особисті завдання працюють без підключення облікових записів.

`npm run dev` запускає Vite на порту 5173 і пересилає `/api` на сервер. Для локальної авторизації значення `DAYFRAME_PUBLIC_URL` і зареєстровані адреси повернення мають відповідати порту 5173. `npm run preview` показує лише статичну збірку й не запускає сервер авторизації.

## Підключення

Для календарів доступний [прямий вхід Microsoft і Google без сервера](docs/DIRECT-LOGIN.md). Події відображаються й оновлюються в календарі Dayframe. Потрібні лише публічні Client ID зареєстрованих застосунків; паролі вводяться на сторінках провайдерів.

Спочатку підключи робочий і особистий Outlook, потім Календар Google та Slack. Потрібні серверний хостинг і одноразова реєстрація OAuth-застосунків. [Інструкція з підключення](docs/CONNECTIONS.md) містить дозволи, адреси повернення та назви змінних середовища. Секрети зберігаються лише в налаштуваннях серверного хостингу.

- `server/config.mjs` — адреси сервісів, дозволи лише для читання та вимоги до конфігурації.
- `server/app.mjs` — обмін кодів авторизації, PKCE для Microsoft і Google, перевірка стану, захищені HttpOnly-сеанси, оновлення токенів, API читання даних і розміщення інтерфейсу.
- `server/mappers.mjs` — перетворення відповідей сервісів на спільні моделі з урахуванням часового поясу.
- `src/data/live.ts` — типізований клієнт API. Токени не потрапляють у localStorage.
- `src/useWorkspace.ts` — власні й демонстраційні дані, оновлення, часткові помилки, усунення дублікатів і вибір періоду.
- `src/components/IntegrationSettings.tsx` — стани підключень, авторизація, відключення та вибір каналів Slack.
- `src/data/mock*.ts`, `providers.ts` — окремі демонстраційні дані українською. Приклади Jira та Confluence не використовуються застосунком.
- `src/appearance.ts` — каталог 14 тем і 6 маскотів; вибір зберігається локально.
- `src/components/Mascot.tsx` — оригінальні SVG-персонажі з пружними рухами, помахами та святкуванням виконаних завдань. Анімації враховують системне зменшення руху.
- `src/locale.ts` — українські підписи, локальний формат дат і правила відмінювання числівників. Внутрішні ключі збережених налаштувань не перекладаються.
- `src/types.ts` — типи моделей.
- `src/App.tsx` — розділи «Сьогодні», «Календар», «Робота», «Особисте», пошук, сповіщення та редагування завдань.
- `src/styles.css` — адаптивний вигляд, чотирнадцять тем і підтримка зменшення анімацій.

Дані Slack — результати пошуку, а не ШІ-огляд. Зовнішні джерела доступні лише для читання. Серверні сеанси зберігаються в пам’яті, діють до восьми годин і потребують повторного підключення після перезапуску. Особисті завдання й налаштування зберігаються в браузері. Виконані повторювані завдання знову відкриваються, коли настає наступна дата й застосунок відкритий. Фонового планувальника та синхронізації між пристроями немає.

Українізація не змінює користувацькі назви, власні нотатки чи тексти з реальних сервісів. У незмінених початкових завдань перекладаються лише назви; їхні дати, стани та правила повторення зберігаються.

## Публікація

GitHub Pages автоматично публікує статичні файли після змін у `main`. Там працюють особисті завдання й явно позначений деморежим. Реальні підключення потребують серверної версії: скористайся шаблоном `render.yaml` або іншим хостингом Node.js 24. Збірка: `npm ci && npm run build`; запуск: `npm start`. На серверному хостингу налаштуй адресу HTTPS та облікові дані OAuth. Сам шаблон не створює хостинг.

## Mac

[Установлення та варіанти збірки для Mac](docs/MAC.md). У Safari на macOS Sonoma або новішій можна додати Dayframe до Dock як окремий вебзастосунок. Нативний інсталятор `.dmg` зараз не створюється.

## Перевірки

```sh
npm test
npm run build
npx playwright install chromium
npm run test:browser
```

Серверні тести перевіряють стан авторизації, PKCE, відсутню конфігурацію, незалежне підключення двох Outlook, відключення, оновлення токенів, пагінацію, часові пояси та читання Slack на локальних прикладах. Реальні облікові дані не використовуються. Браузерні тести перевіряють навігацію, українські підписи, завдання, збереження даних, режими джерел та мобільний вигляд. Реальна авторизація залишається неперевіреною, доки облікові записи не налаштовані та не підключені.

Якщо Chromium уже встановлений, укажи шлях до нього в `PLAYWRIGHT_CHROMIUM_EXECUTABLE` замість завантаження браузера. Команда `npm run test:browser` за потреби запускає сервер із готової збірки.


## Практичне планування

Підходи та межі порівняння популярних календарів описані в [рішеннях щодо інтерфейсу](docs/DESIGN-DECISIONS.md). Зовнішні офіційні сторінки під час роботи були недоступні через мережеву відмову; це не живий аудит усіх сервісів.

Головна показує розклад і до чотирьох актуальних справ; завершені згорнуті. «Особисте» розділяє сьогодні, найближчі сім днів, усі справи та необов’язкові шаблони. Побутові заготовки не є активними завданнями, доки їх не заплановано. Позначки дати, прострочення, повторення й важливості пояснюють різницю між справами.

- `src/components/CalendarBoard.tsx` — шкала часу, день/тиждень/місяць/список, фільтри, перехід до дати та окремі завдання без часу.
- `src/components/PersonalBoard.tsx`, `TaskList.tsx` — згруповані списки, пошук, завершення, перенесення, редагування й бібліотека.
- `src/components/EventDetails.tsx` — подробиці події з посиланнями лише за наявності справжніх адрес.
- `src/domain/planning.ts` — коректне переміщення дат, прострочені справи, перекриття подій, перехід через північ і обережна міграція старих заготовок.

Перенесення виправлено: локалізована дата більше не використовується як машинна. Конкретні завдання зі Slack створюються лише після введення назви й підтвердження, а не з цілого абзацу повідомлення автоматично.

### Беклог і Jira вручну

«Особисте» — єдиний простір без вкладок із блоками «Беклог», «Рік», «Місяць», «Тиждень», «День». Річну справу можна перетягнути в цей місяць, потім у цей тиждень і на конкретний день. Місяць і тиждень зберігають обраний період без довільного дедлайну; у календар потрапляють лише справи з конкретною датою. Цикл повторення незалежний від блоку: «Щороку» залишається «Щороку» навіть у тижневому плані. Наявні шаблони згруповані за циклом (квартальні — в річному блоці); перенесення шаблону створює копію. Звичайне завдання переміщується. Для телефона й клавіатури є вибір блоку, кнопки «На сьогодні» / «На завтра» та вибір дати. Виконані й призупинені справи розгортаються нижче.

«＋ У беклог» створює ідею без дати. «Додати з Jira вручну» зберігає вставлену назву як разове завдання у беклозі; необов’язкове HTTPS-посилання відкриває оригінальний тікет. Це локальна копія без API або синхронізації статусів. Дані зберігаються в цьому браузері.

### Паперові оформлення календаря

«Пастель» — початкове оформлення для нових налаштувань. «Милий планер», «Вінтаж» і «Магічний пергамент» доступні через «Оформлення» в календарі та загальний перемикач тем у налаштуваннях. Збережені теми користувача залишаються доступними. Спільні матеріали, кольори, шрифти, рамки й тіні визначені в `src/planner.css`; статичні ілюстрації — у `public/assets/planner` та `src/components/PlannerDecoration.tsx`. Паперові теми використовують статичний декор замість анімованого фону.

У місячному режимі на телефоні обрана дата відкриває список подій і завдань під сіткою. Режим дня має погодинну шкалу навіть без підключених календарів. Події Outlook/Google залишаються лише для читання; особисті завдання можна створювати, редагувати й виконувати.

### Компонування щоденного планера

Режим «День» має окремі робочі секції: три пріоритети й справи ліворуч, високий розклад у центрі, нотатки й нагадування праворуч. На телефоні порядок: пріоритети → розклад → справи → нотатки → нагадування. Форми, вкладки, аркуші та їхні пропорції визначені в `src/planner-layout.css`; стан секцій — у `DayPlanner.tsx`.

Пріоритети, відмітки виконання, нотатки й нагадування зберігаються за датою в `dayframe-daily-plans` у цьому браузері. Нагадування можна додавати, редагувати (текст і час), виконувати й видаляти; це список усередині планера, без системних сповіщень. Особисті завдання використовують попереднє сховище та звичайний редактор. Календарі постачальників залишаються лише для читання.

Готові прозорі ілюстрації та іконки зберігаються в `public/assets/planner`; походження й використання описані в README цієї папки. В усіх режимах залишаються ті самі дані, переходи дат, фільтри й деталі подій. Місяць оформлений як сітка окремих аркушів, тиждень — як часовий планер із вкладками днів.

### Об’ємне оформлення всіх тем

`src/theme-finish.css` застосовує спільний набір рамок, піднятих вкладок, об’ємних кнопок, внутрішніх тіней полів і тематичних текстур до всіх 18 тем. Палітри та кольори маскотів збережені; темні теми використовують власні відблиски й контрастний текст. Оформлення охоплює календар, дошку, картки, налаштування та модальні вікна. Анімації появи, натискання й ілюстрацій вимикаються через системне `prefers-reduced-motion`.

### Реакції на дотики

Усі теми мають короткі реакції на натискання: пружний відгук кнопки, кільце й тематичні частинки (сердечка, листочки, зорі, хмаринки або квіти). Ефекти працюють також із клавіатури, не перехоплюють натискання, обмежені п’ятьма одночасними спалахами й автоматично прибираються. Вони не створюють звуку або вібрації. `prefers-reduced-motion` вимикає рух, залишаючи звичайні контрастні стани фокусу й натискання.

Помічник у заголовку календаря реагує на привітання короткою анімацією та реплікою. Під час перетягування картка піднімається, а блок призначення підсвічується. Реалізація: `TouchFeedback.tsx`, `CalendarCompanion.tsx`, `touch-feedback.css`.

### Мопс, idle-анімації, скло й швидкі віконця

У виборі помічника є **Мопс Бублик**. Його палітра залишається незмінною в темних темах. Стандартний idle персонажів — легке дихання, коротке кліпання й рідкі рухи вушок; мопс також рухає хвостом і язичком. На привітання персонаж підморгує одним оком, мопс коротко виляє хвостиком. Вибраний персонаж відображається в заголовку календаря в будь-якій темі.

`glass-rubber.css` додає всім темам напівпрозорі матові поверхні, відблиски, розмиття тла й пружне стискання елементів. Є непрозорий запасний варіант; системне зменшення руху вимикає анімації, а зменшення прозорості прибирає розмиття.

У календарі є швидкі віконця «Дата», «Справи», «Нотатки» та «Нагадування». Мінікалендар перемикає дату, справи використовують наявний редактор, а нотатки й нагадування ділять один стан із аркушем дня (`useDailyPlan`). Escape, хрестик або натискання поза віконцем закривають його. Використані знайомі патерни мінікалендаря та швидких панелей Google Calendar, Outlook і Apple Calendar; це не нові інтеграції із сервісами.

### Спокійне сучасне оформлення

`modern-soft.css` уточнює всі теми: тонкі рамки, легкі тіні, матове скло, чисті заголовки секцій і стримані стани кнопок. Важкі підкладки, глянець та постійне підстрибування персонажів прибрані. Мопс перемальований зі світлою мордочкою, маленькими блискучими очима та рожевими щічками. Окремі SVG-групи очей підтримують коротке природне кліпання й підморгування.

### Google Keep

[Локальний імпорт Google Takeout](docs/KEEP-IMPORT.md): ZIP, JSON або тека Keep. Попередній перегляд дат, збереження тексту, зображень, посилань і чеклістів, автоматичне створення відсутніх розділів за мітками або темами. Приватний акаунт не відкривається за посиланням і не читається без доступу до його даних.

### Спорт і кроки

Розділ «Спорт» зберігає силові вправи й кардіо за датами: підходи, повторення, вагу, тривалість та виконання. Кроки вводяться вручну; є щоденна ціль, швидке додавання та графік за останні сім днів. Дані локальні (`dayframe-fitness`) і входять у резервну копію календаря; імпорт додає відсутні дні, зберігаючи наявні записи. Автоматичного читання даних годинника немає.

### Огляд дня, погода та підтримка

«Сьогодні» містить редаговані пріоритети й нотатки дня, нагадування, спорт, кроки та всі актуальні завдання. Перемикач періоду показує справи й події на тиждень, місяць, квартал або рік. Погода береться з Open-Meteo для вибраного міста (початково Київ), оновлюється раз на 15 хвилин і при поверненні на екран; геолокація запитується лише кнопкою. При помилці показується попередня погода з позначкою або відсутність даних. Ілюстрації дощу й снігу відповідають кодам погоди.

Окремі картки афірмацій і цікавинок показуються одночасно й мають незалежне ручне перемикання та інтервали 1/5/15/30/60 хвилин. Налаштування зберігаються локально; факти мають посилання на джерела. Анімації враховують налаштування зменшення руху.

### iPhone та Apple «Здоров’я»

[Інструкція збірки iOS та поведінка HealthKit](docs/APPLE-HEALTH.md). Підготовлено native-запит читання кроків і тренувань; для реального доступу потрібні збірка, встановлення iOS-застосунку та дозвіл користувача на iPhone. Вебсайт цього доступу не отримує.

### Особистий планер і чат із помічником

Огляд «Сьогодні» містить дошку «Мої плани → На сьогодні → Готово». Перетягування працює за ручку на картці; список перенесення дозволяє виконати ту саму дію без жесту. Перенесення зберігає нотатки й повторення, а завершення розраховує наступне повторення. Є окремий трекер звичок за референсом: сім днів тижня, щотижневі відмітки, 12 місяців, чотири квартали та рік. Відмітки, порядок справ і записи самопідтримки входять у резервну копію.

Мескот показує актуальну справу або нагадування, відкриває її редактор і може відкласти підказку на 15 хвилин, доки планер відкритий. Кнопка розмови веде до вбудованого чату. Підтримка й цікавинки показуються одночасно та мають незалежні інтервали зміни.

У картці чату користувач вводить власний API-ключ OpenAI та модель (початково `gpt-4.1-mini`). Запити виконуються напряму до `https://api.openai.com/v1/responses`, без сервера Dayframe. Потрібен доступний API-баланс; підписка ChatGPT не замінює API-ключ. Ключ та історія чату живуть лише в пам’яті сеансу, не включаються в резервні копії та не записуються в репозиторій. Запит містить лише повідомлення чату (до 12 останніх), `store: false` та інструкцію режиму. Нотатки турботи, календар і здоров’я не додаються автоматично. Самопідтримка не є діагностикою або заміною психотерапії.
