# Окрема технічна задача: фонові нагадування

Поточна реалізація перевіряє особисті записи таймером у відкритому Dayframe та показує повідомлення всередині застосунку. Дозвіл Notifications не потрібен. При закритій вкладці доставки немає; браузер також може призупиняти таймери неактивної вкладки. Ці обмеження видно в редакторі до збереження.

Фонові сповіщення не входять у цю зміну. Для окремої реалізації потрібно визначити підтримувані платформи, поведінку без мережі та часовий пояс; спроєктувати планування й доставку (сам service worker не гарантує запуск у заданий час), явний запит дозволу, відкликання підписки, дедуплікацію й перенесення/скасування повторень. Приймання: вкладка відкрита, неактивна, закрита; перезапуск браузера; дозволено/заборонено сповіщення; перехід на літній час; відсутність мережі. До такого приймання не обіцяти гарантовану фонову доставку.
