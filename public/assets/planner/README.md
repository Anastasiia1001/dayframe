# Асети планера

Оригінальні ілюстрації створено інструментом генерації зображень для Dayframe з прозорим тлом. Використовуються як декор, не містять робочих полів або написів.

- `bunny-calendar.png` — головна композиція: кремовий зайчик і календарик.
- `plant.png` — рослина в кремовому горщику з бантиком.
- `stationery-set.png` — узгоджений набір глиняних наліпок: сердечко, зірочка, хмаринка, бантик, скотч, кнопка-шпилька, книги й чотири іконки навігації. Окремі елементи показуються CSS-спрайтами без зміни вихідного зображення.
- `work.svg` — окрема векторна іконка робочого розділу з тією самою палітрою.

Герой і рослина підключені як декоративні `img` з порожнім `alt`; наліпки мають `aria-hidden`. Усі декоративні накладки ігнорують натискання. Паперові й пергаментні теми використовують окремі ботанічні/гравюрні SVG-мотиви з `PlannerDecoration`, не пастельні наліпки.
